# Examples

Everything here is **synthetic and illustrative**. The data is generated by
[`generate_data.py`](generate_data.py) from a fixed seed (`make data` reproduces it byte for
byte), and the policies are not real underwriting, fraud, claims or clinical guidance.

| Folder | Domain | Try |
|---|---|---|
| `lending/` | mortgage pre-qualification | `rulelens diff lending/policy.toml lending/policy_v2.toml lending/applications.csv --group-by region` |
| `fraud/` | card-not-present payments | `rulelens diff fraud/policy.toml fraud/policy_v2.toml fraud/transactions.csv --id-field txn_id` |
| `claims/` | insurance claims triage | `rulelens simulate claims/policy.toml claims/claims.csv` |
| `trials/` | clinical-trial pre-screening | `rulelens simulate trials/policy.toml trials/screening.csv --group-by site` |
| `lint_demo/` | support-ticket routing | `rulelens lint lint_demo/policy.toml` |

Each policy carries `[[tests]]`; run them with `rulelens test <policy>`.

The lending data deliberately gives one region lower average income and credit scores so the
outcome-rate audit has something to find. That is a property of the made-up data, not a claim
about any real lender or region.
